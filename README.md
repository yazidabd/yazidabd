### Featured Projects

**[de-cdc-lakehouse-pipeline](https://github.com/yazidabd/de-cdc-lakehouse-pipeline)** (in progress)
CDC and Delta Lakehouse pipeline for a fintech dataset. PostgreSQL as the transactional source, Debezium for change data capture, Kafka as the message broker, and Delta Lake on MinIO/S3 as the lakehouse storage layer, with a PII detection and masking layer before data reaches the lakehouse.

**[de-cloud-elt-pipeline](https://github.com/yazidabd/de-cloud-elt-pipeline)**
Batch Cloud ELT pipeline for e-commerce data. Infrastructure provisioned with Terraform, data landed and transformed in Snowflake with dbt (staging to marts star schema), orchestrated by Airflow, pushed to Airtable via Reverse ETL, and visualized with a Streamlit dashboard. Hardened with incremental models, backfill support, schema validation, and CI/CD.

**[de-iot-pipeline](https://github.com/yazidabd/de-iot-pipeline)**
Real-time IoT/sensor data pipeline. Weather data ingested via a Kafka producer, processed through Spark Structured Streaming into a Bronze/Silver layered architecture, loaded into PostgreSQL, and modeled with dbt (incremental, tested) on a 15-minute Airflow schedule. Includes CI/CD with pytest and dbt tests.
